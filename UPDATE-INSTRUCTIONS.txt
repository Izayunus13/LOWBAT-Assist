LOWBAT Assist — Migrasi Supabase ke Turso

1. Buat database Turso.
2. Jalankan isi file turso-setup.sql pada database tersebut.
3. Ambil database URL dan buat auth token Turso.
4. Di Vercel, tambahkan:
   TURSO_DATABASE_URL
   TURSO_AUTH_TOKEN
5. Deploy project.
6. Buka website dan cek status database harus "Terhubung — riwayat tersinkron".
7. Generate satu jarkoman dan cek Riwayat Bersama.

Catatan:
- Jangan masukkan TURSO_AUTH_TOKEN ke file JS frontend.
- UI/tampilan dan fitur non-database tidak diubah.
- Supabase sudah dilepas dari project.
